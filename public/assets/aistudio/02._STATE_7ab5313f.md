# State Machine

## Arabic Typing Learning App

**Status:** Draft v1.0

This document defines the learner and exercise states. It is the source
of truth for progression behavior.

## 1. Core states

-   `HOME` --- learner is on the app home screen.
-   `STAGE_OVERVIEW` --- learner views the current curriculum stage.
-   `MODE_SELECTION` --- learner chooses an unlocked mode.
-   `EXERCISE_READY` --- exercise is loaded and waiting to begin.
-   `EXERCISE_ACTIVE` --- learner is typing.
-   `ERROR_FEEDBACK` --- an incorrect key was pressed; learner remains
    on the same required position.
-   `EXERCISE_RETRY` --- the current exercise is restarted or the
    learner retries the current item, according to the selected retry
    policy.
-   `EXERCISE_COMPLETE` --- the exercise has been completed with no
    disqualifying mistakes.
-   `REPORT` --- result report is displayed.
-   `STAGE_UNLOCKED` --- next stage/mode has become available after
    successful completion.

## 2. Mode behavior

### Guided Mode

-   On `EXERCISE_READY`, identify the next expected character and
    highlight its key.
-   On correct keypress: record correct input, move to the next
    character, update key highlight.
-   On incorrect keypress: record mistake, enter `ERROR_FEEDBACK`; do
    not advance the expected-character pointer.
-   Return to the same required character after feedback.
-   Complete only when the full target is entered according to the
    no-mistake completion rule.

### Hint Mode

-   Start with no next-key highlight.
-   On correct keypress: advance to the next expected character without
    a hint.
-   On incorrect keypress: record mistake, reveal/highlight the correct
    key, and remain at the same expected character.
-   A mistake prevents successful completion of that attempt.
-   Do not unlock the next mode from an attempt containing a mistake.

### Test Mode

-   Never highlight a key.
-   Never show a key hint.
-   On incorrect keypress: record the mistake and remain at the same
    expected character.
-   Complete the test only after the target is entered; report the
    errors. A test with errors is not a clean mastery completion.

## 4. Unlock logic

-   Mode 1 (Guided) is initially available.
-   Mode 2 (Hint) unlocks only after a clean completion of the
    corresponding Guided exercise.
-   Mode 3 (Test) unlocks only after clean completion of the
    corresponding Guided and Hint exercises.
-   The next curriculum stage unlocks only after the required
    current-stage learning work is completed cleanly.
-   Any mistake means the current attempt is not a clean completion. The
    learner stays at the current stage/mode and retries.
-   Do not assume a specific number of retries or attempts; this remains
    a product decision.

## 5. Input and scoring definitions

-   `expected_index` points to the next required character.
-   Correct input advances `expected_index` by one.
-   Incorrect input increments `mistake_count` and leaves
    `expected_index` unchanged.
-   Backspace behavior must be consistent. Recommended default:
    backspace may remove a previously entered character but must not
    erase the historical fact that an incorrect keypress occurred.
-   Timer starts when the first exercise input is accepted or when the
    learner taps Start; choose one behavior and apply consistently.

## 6. RTL and keyboard states

-   Arabic text area uses right-to-left direction.
-   Keyboard key state values: `default`, `highlighted`, `pressed`,
    `disabled`.
-   In Test Mode, `highlighted` is never used.
